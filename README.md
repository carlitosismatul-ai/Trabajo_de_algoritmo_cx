## Glosario 
<br> 1) IA: Rama de la computación que desarrolla sistemas capaces de aprender, analizar información y tomar decisiones de manera automática. </br>
 <br> 2) Computo: Proceso mediante el cual una computadora realiza cálculos y operaciones para transformar datos en información útil. </br>
<br>3) Nube: Tecnología que permite almacenar y procesar información a través de internet sin depender de un solo equipo físico. </br>
<br>4) Sotfware: Conjunto de programas y aplicaciones que indican a la computadora cómo funcionar y qué tareas realizar. </br>
<br>5) Hardware: Parte física de la computadora, como el teclado, monitor, procesador y memoria. </br>
<br>6) Datos: Información en forma de números, textos, imágenes o sonidos que puede ser procesada por una computadora. </br>
<br>7) Procesos: Conjunto de operaciones que ejecuta el sistema para transformar los datos de entrada en resultados. </br>
<br>8) Entrada:  Datos o instrucciones que el usuario introduce a la computadora mediante dispositivos como teclado, mouse o micrófono.            </br> 
<br>9) Salida: Información que la computadora presenta al usuario después del procesamiento, como imágenes en pantalla o impresiones.  </br>
<br>10) Almacenamiento: Capacidad de guardar datos e información en dispositivos físicos o en la nube para su uso posterior. </br>
<br>11) Usuario: Persona que interactúa con un sistema informático para introducir datos, ejecutar programas u obtener información.              </br>
<br>12) Procedimiento: Serie de pasos ordenados que se siguen para realizar una tarea específica dentro de un sistema. </br>
<br>13) comunicaciones: Proceso de intercambio de información entre computadoras o dispositivos a través de redes. </br>
<br>14) Sistema:  Conjunto de elementos relacionados (hardware, software, datos y personas) que trabajan juntos para cumplir una función.           </br>
<br>15) Riesgo: Posibilidad de que ocurra una falla, pérdida de información o ataque que afecte a un sistema informático.              </br>
